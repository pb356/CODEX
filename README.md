# 植价：浏览器版

静态植物报价网页。报价与上传文件在自己的浏览器处理，无服务器、无登录。

## 使用

1. 打开部署后的HTTPS网站。网页没有内置用户报价。
2. 左侧“导入植物报价库”：上传带植物名称、规格、单位、单价的XLSX/CSV。支持所有工作表、每表前30行定位表头、独立高度/冠幅等列；无植物名称的费用项排除。相同规格和单位的再次导入更新库价，一份文件中的归一化冲突报价拒绝保存。
3. 右侧上传新清单，自动使用价格库填价。高度/株高/H、冠幅/P等常见写法、顺序、全半角、棵/株以及明确的米/厘米写法可对应。尺寸未标单位的常见带标签规格默认厘米。不同大小、胸径和地径、盆和株、A/B名称版本不自动等价。
4. 没有规格、不同规格或多个候选时，正式价格留空并说明原因。可从参考报价下拉框选择，经“确认采用”后更新本行品种、规格、单位和价格。
5. 价格库为空时明确提示。先读清单后导入价格库会自动重新填价；人工填写和人工确认过的报价保留，点击“重新匹配”则按库价重新计算。
6. PDF/PPTX读取可提取文字，用有限植物词表与价格库生成草稿；不识别扫描件，不推算数量，备选方案不可直接叠加计量。
7. 核对后导出标准Excel清单。定期“备份价格库”，恢复时重新导入备份。原文件图片、版式与包干折扣不随标准清单导出。

## 旧模板合并

独立“我的报价模板”模块已移除。第一次打开新版时尝试从旧IndexedDB模板中恢复有效报价，合并到现有价格库；已有库价优先，多个旧模板的同规格不同价格不自动选择。不完整或冲突报价须重新导入原报价文件。旧原文件暂留浏览器旧存储作为恢复副本，不再提供模板管理界面，避免升级时误删用户文件。

价格保存在当前浏览器、当前网站来源下，不在设备间同步。清除网站数据会删除本机价格与旧模板恢复副本。隐私模式关闭后可能丢失，请及时导出备份。文件仅在本机解析；网站不调用上传API或第三方模型。

单文件上限20MB；复杂文件可能占用较多内存。工作簿中可识别的清单工作表会合并读取，不可识别的封面忽略。表内合并单元格只读左上角，不把合计误当植物名。

## GitHub Pages

本分支为独立静态发布分支，不包含用户上传文件、价格数据库、登录密码或Python桌面程序。

工作流尝试自动配置并发布Pages；如GitHub提示站点尚未启用或权限不足，仓库管理员需在 Settings → Pages → Build and deployment 中选择 GitHub Actions，然后在 Actions 中重新运行 Publish plant pricing website 工作流。若组织策略要求批准发布环境，也需由仓库管理员确认。

预计路径为 https://pb356.github.io/CODEX/ ，以Pages设置页或成功工作流显示的实际地址为准。分支推送成功不代表Pages发布成功。

本地预览：`python -m http.server 8123 --directory web_static`（从项目父目录运行），通过本地HTTP访问；不支持直接双击HTML文件的file协议。

## 第三方组件

ExcelJS 4.4.0、JSZip 3.10.1、PDF.js 4.10.38。随附许可证在 vendor 目录。
