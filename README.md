# 植价：浏览器植物报价助手

公开静态网址：https://pb356.github.io/CODEX/ 。报价和文件在自己的浏览器处理，没有上传接口或第三方模型调用。价格库保存在当前浏览器，不在设备间同步；清理网站数据会删除本机库，请定期导出备份。

## 使用

1. 左侧导入带品种、规格、单位、单价的Excel/CSV报价表。可连续导入多份，保留不同来源和价格，同一来源、规格和价格的重复记录去重，新导入文件以内容指纹区分同名文件。价格库备份保留来源及文件标识，恢复后不重复加权。
2. 右侧上传新清单，点击“识别并匹配价格”，自动查询整个库，不需选择模板。
3. 同品种、单位相容、规格相同/在库中范围内/逐尺寸超界偏差在容差内的全部有效报价参与简单算术平均。默认容差10%，可选择0/5/10/20/30%。没有相应尺寸、品种无报价或计量单位不同，不会强行猜价。
4. 两条及以上有效报价先求平均，四舍五入到整数元，再按个位：1–3降到0、4–7改为5、8–9进到下一整十、0保持。例：均价103→100，104→105，108→110；小数103.5先到104，再取105。仅一条有效报价保留原价。重复导入相同报价不额外加权。
5. 目标品种/规格保持原清单内容，另显示库中采用规格、报价数、原始均价、来源和最终单价。可以手动修改；后续重新匹配会按现行设置计算。
6. 上传XLSX时默认原格式导出；上传CSV/PDF/PPTX时生成带金额、税额、合计和报价依据的标准Excel表。

## 原格式填价与计算

不使用ExcelJS重建用户工作簿，而用JSZip修改原OOXML包中的价格、金额、必要公式及缓存。图片、绘图、样式文件等资源不重新编码，合并区域、行高、列宽、打印设置和其他表内容保留。默认写入原单价/金额列；若没有对应列则追加到右侧，并提示原打印范围不扩展。

- 原文件中的数量、价格、金额对应行有明确记录；界面修改单价和数量会写回原位置。移除项目仅清空原行的价格/金额，不移动其他行，避免破坏图片和合并区域。
- 金额、小计、税额、合计以数值和公式写入，不再导出成数字字符串。非植物的花盆、运费、人工等原表费用保留并参加原表计算。
- 默认沿用原税费及公式。可以选择“库价未税加税”并输入百分数，或“库价已含税不再加税”。无原税费时使用手动补充税率；无法确定时不猜测、不重复加税，列入核对提示。
- 原表税率可读文字百分比或税率标签附近的百分比单元格。含税表不自动加一遍发票税率；多种复杂税种仍需人工核对。
- 固定“折后/包干小计”默认保留并提示人工核对；可选择按更新行金额重新求和，此时不应用原固定折扣，不擅自推算折扣率。
- SUM/ROUND/SUBTOTAL(9)/IF/IFERROR等常见公式及跨表引用可计算缓存，共享公式先展开为等价逐行公式。其他复杂公式保留，清除旧结果缓存，并要求Excel打开时重算；不声称支持完整Excel计算引擎。
- 导出新增“报价计算核对”页，列出税费口径、合计、待核对项、均价和每条参与报价。原表没有合计行时末尾增加合计，打印范围保持原设置，需自行核对打印区域。
- 缺单价/数量的行金额留空，导出前提示，文件标记待核价。网页新增但无原表位置的项目须先添加到原Excel，或选择标准表导出，避免无提示地移动原表结构。
- 原格式仅支持XLSX，CSV没有图片/合并样式可保留；PDF/PPTX文字提取生成草稿，不是复刻原方案版式。

## 解析与数据迁移

自动检查所有工作表的前30行，支持品类、规格cm、高度/冠幅分列等。合并单元格只读左上角，汇总行不当植物。每份文件上限20MB。规格支持H/高度/株高、P/冠幅、胸径/地径等及明确米厘米转换；没有标注尺寸单位的常见带标签规格默认厘米。盆和株不能混合平均；通用品名可按库中A/B/数字分档的相应规格找价，明确不同品种仍分开。

旧“我的报价模板”独立模块已移除。打开新版时尝试将旧本地模板中的有效报价合并到库中，保留已有记录，不完整报价不猜测。旧原文件暂留旧IndexedDB作为恢复副本，界面不再提供模板管理。此前已被旧版本覆盖的历史报价无法凭空恢复，可重新导入原报价文件。

`.github/workflows/pages.yml` 发布独立gh-pages分支，部署后检查网页及各模块HTTPS响应。该分支没有真实用户报价、原始方案、数据库或密码。发布成功后以GitHub Pages展示的地址为准。
