# 植价：浏览器版

静态植物报价网页。报价与上传文件在自己的浏览器处理，无服务器、无登录。

## 使用

1. 打开部署后的HTTPS网站。初始价格库为空，网站未内置任何用户报价。
2. 上传XLSX或CSV报价表，支持前30行自动查找表头，兼容“品类”和“规格cm”。首次导入原始室内外清单应有17个植物规格。无植物名称的花盆、材料和人工行排除并提示。
3. 在“我的报价模板”中可一次上传多份XLSX/CSV，保存原文件和解析后的清单；模板无需单价。可使用模板按当前价格库填价、下载原模板或删除。模板使用后导出标准清单，不保留原版式图片或公式；同名文件作为不同模板分别保存。模板存于当前浏览器IndexedDB，清理网站数据也会删除它们。
4. 上传新清单按名称、规格、单位填价。缺失或冲突价格不猜测。
5. 文字PDF/PPTX可根据有限植物词表和价格库生成辅助草稿，不支持扫描件/OCR，不推算数量或规格。A/B等名称候选仅列为参考，不自动等价。备选方案须人工分别计量。
6. 手动核对后导出Excel；用“备份价格库”定期导出备份，恢复时重新导入该文件。

数据只在当前浏览器、当前网站来源下保存。清理浏览器数据、切换网址/设备/浏览器会导致报价不可见；隐私模式关闭后可能丢失。网页没有上传API、分析统计或远程模型服务。第三方解析库与字体文件随站点一起托管，不从第三方CDN加载。

单文件上限20MB，复杂文件可能占用较多本机内存。XLSX读取第一个工作表；导出为标准清单，不保留原文件图片、格式、点位与包干折扣等费用条款。

## GitHub Pages

本分支为独立静态发布分支，不包含用户上传文件、价格数据库、登录密码或Python桌面程序。

工作流尝试自动配置并发布Pages；如GitHub提示站点尚未启用或权限不足，仓库管理员需在 Settings → Pages → Build and deployment 中选择 GitHub Actions，然后在 Actions 中重新运行 Publish plant pricing website 工作流。若组织策略要求批准发布环境，也需由仓库管理员确认。

预计路径为 https://pb356.github.io/CODEX/ ，以Pages设置页或成功工作流显示的实际地址为准。分支推送成功不代表Pages发布成功。

本地预览：`python -m http.server 8123 --directory web_static`（从项目父目录运行），通过本地HTTP访问；不支持直接双击HTML文件的file协议。
