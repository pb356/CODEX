# 植价：浏览器植物报价助手

公开静态网址：https://pb356.github.io/CODEX/ 。报价和文件在自己的浏览器处理，没有上传接口或第三方模型调用。价格库保存在当前浏览器，不在设备间同步；清理网站数据会删除本机库，请定期导出备份。

## 室外 / 室内双工作区

页面顶部切换“室外植物报价”和“室内植物租赁”。两个工作区各自运行独立页面实例，分别保存价格库、原始工作簿、清单、文件选择、计价设置、异步处理和下载链接；切换只隐藏页面，不销毁进度。价格库及设置跨刷新保留，当前清单及原文件仅保留本次页面会话，刷新后需重新上传。

原室外库继续使用原来的本地存储键，不重命名或清空；室内库使用独立键，初始为空。旧模板恢复只在室外执行。备份包含工作区标识，跨业务导入会提示切换而不写入。所有真实报价和上传文件仅在浏览器处理，公开站点不内置用户报价。

### 室内租赁

- 默认按月，支持月/天/年计租；每条报价记录自己的计租周期，自动匹配和均价只使用当前周期，不能将月价和日价混合平均。
- 支持“元/月”“月租金”等表头，无单位列时采用可选缺省单位（默认盆），不假称原文件列明了单位。
- 金额=数量×对应周期单价×租期；原表有逐行租期时优先采用，租期须为正数。改变计租周期不自行换算30天/月或12月/年，需确认租期数值。
- 按用户室内样表适配“赠送”：原清单中赠送行保留价格和备注但金额为0，不作为常规租金报价入库，避免零价或赠品标价污染正常租赁价格。
- 原表“含税合计”沿用，不重复加税。“实收”为单独的协商金额：无逐行租期时按固定每周期实收×当前租期计算；可通过固定价设置改为按行重新计算。实收不摊入每盆的参考租金，也不带入其他项目。
- 原格式导出保留原图片、合并、排版；必要时追加租期列。室内植物金额按数量×周期单价×租期重算，行公式中的额外折扣需核对。非植物独立费用不自动按租期倍增。
- 室内导出文件加“室内租赁”前缀。室内/室外均保留多报价自动均价、个位取值、PDF/PPTX文字提取、税费、核对页及可靠下载功能。

## 可编辑预览与新品类库

Excel/CSV按原顺序保留植物、未知品种、花盆、辅材、人工、运输等明细。植物列为空时从点位/项目/说明等字段取得项目名，无法命名的金额行也保留为待编辑项目。汇总与脚注不重复当作收费项目，可展开导入原文对照。PDF/PPTX仍是基于可提取文字的辅助草稿，不承诺完整识别所有未知名称。

- 名称、规格、单位、数量、单价、金额、备注、类别以及其他原表文字字段可在预览中编辑。非主格的合并附属字段提示去首行编辑，避免把修改写入被合并遮住的格子。
- 原文件已有但未匹配的单价、单独金额保留；用户填入有效单价后才可登记新品报价。金额可手动覆盖，也可“恢复计算”。改数量/单价会恢复计算，手动总金额不会被当成单位价格存入库。
- “预览最终报价”使用与导出相同的原工作簿计算器读取金额和税费/折后实收；编辑后提示重新预览，防止旧总价误用。无法计算的原复杂公式保留并标为待Excel重算。
- 新品可逐行“一键加入新品库”，也可批量存入已填价项目。名称和单位必填，单价须为非负数，规格可空。赠送行不作为正常报价，批量中同名同规格不同手填价须先明确，不能静默覆盖。
- 新品库支持新增、逐行编辑保存、删除、独立Excel备份与恢复；不改写普通植物库。其明确报价优先，找不到适用新品报价才使用普通库，适用普通库的多报价均价规则保持。
- 室外/室内各有自己的普通库和新品库及编辑草稿，跨业务备份不接受。室内新增的人工、安装等其他项目默认一次性，不重复乘租期；确需按周期收费可明确选择。
- 导出将费用描述写回正确原列，而非塞入植物品种列；金额覆写、备注及其他字段修改一并写回。原图和版式继续保留。新增但无原表位置的项目可先标准表导出，原格式需在原Excel添加对应行。

## 使用

1. 左侧导入带品种、规格、单位、单价的Excel/CSV报价表。可连续导入多份，保留不同来源和价格，同一来源、规格和价格的重复记录去重，新导入文件以内容指纹区分同名文件。价格库备份保留来源及文件标识，恢复后不重复加权。
2. 右侧上传新清单，点击“识别并匹配价格”，自动查询整个库，不需选择模板。
3. 同品种、单位相容、规格相同/在库中范围内/逐尺寸超界偏差在容差内的全部有效报价参与简单算术平均。默认容差10%，可选择0/5/10/20/30%。没有相应尺寸、品种无报价或计量单位不同，不会强行猜价。
4. 两条及以上有效报价先求平均，四舍五入到整数元，再按个位：1–3降到0、4–7改为5、8–9进到下一整十、0保持。例：均价103→100，104→105，108→110；小数103.5先到104，再取105。仅一条有效报价保留原价。重复导入相同报价不额外加权。
5. 目标品种/规格保持原清单内容，另显示库中采用规格、报价数、原始均价、来源和最终单价。可以手动修改；后续重新匹配会按现行设置计算。
6. 上传XLSX时默认原格式导出；上传CSV/PDF/PPTX时生成带金额、税额、合计和报价依据的标准Excel表。

## 原格式填价与计算

不使用ExcelJS重建用户工作簿，而用JSZip修改原OOXML包中的价格、金额、必要公式及缓存。图片、绘图、样式文件等资源不重新编码，合并区域、行高、列宽、打印设置和其他表内容保留。默认写入原单价/金额列；若没有对应列则追加到右侧，并提示原打印范围不扩展。

- 原文件中的数量、价格、金额对应行有明确记录；界面修改单价和数量会写回原位置。移除项目仅清空原行的价格/金额，不移动其他行，避免破坏图片和合并区域。
- 金额、小计、税额、合计以数值和公式写入，不再导出成数字字符串。非植物的花盆、运费、人工等原表费用保留并参加原表计算。
- 默认沿用原税费及公式。可以选择“库价未税加税”并输入百分数，或“库价已含税不再加税”。无原税费时使用手动补充税率；无法确定时不猜测、不重复加税，列入核对提示。
- 原表税率可读文字百分比或税率标签附近的百分比单元格。含税表不自动加一遍发票税率；多种复杂税种仍需人工核对。
- 固定“折后/包干小计”有原金额时默认保留并提示人工核对，原栏位为空时按新行金额求和并明确未应用折扣，不再阻断导出；可选择按更新行金额重新求和，此时不应用原固定折扣，不擅自推算折扣率。
- SUM/ROUND/SUBTOTAL(9)/IF/IFERROR等常见公式及跨表引用可计算缓存，共享公式先展开为等价逐行公式。其他复杂公式保留，清除旧结果缓存，并要求Excel打开时重算；不声称支持完整Excel计算引擎。
- 导出新增“报价计算核对”页，列出税费口径、合计、待核对项、均价和每条参与报价。原表没有合计行时末尾增加合计，打印范围保持原设置，需自行核对打印区域。
- 缺单价/数量的行金额留空，导出前提示，文件标记待核价。网页新增但无原表位置的项目须先添加到原Excel，或选择标准表导出，避免无提示地移动原表结构。
- 原格式仅支持XLSX，CSV没有图片/合并样式可保留；PDF/PPTX文字提取生成草稿，不是复刻原方案版式。

## 下载与导出反馈

导出进度、错误和继续/取消确认都在导出按钮旁显示，不依赖可能被内嵌浏览器屏蔽的系统确认弹窗。文件生成后尝试自动下载，同时保留“点击下载Excel”链接；链接连接到文档，持续有效到数据或设置改变，不再1秒后销毁，可重复点击重试。修改数据/税费等设置后旧下载入口失效，防止下载过期报价。

原格式模式仍保留原文件；标准表模式不能完整继承原表税费时先在页内说明并确认，文件标注“税费待核对”，不再无提示阻断。未选择税率或没有生成清单等错误就地显示，匹配结果保留。

## 解析与数据迁移

自动检查所有工作表的前30行，支持品类、规格cm、高度/冠幅分列等。合并单元格只读左上角，汇总行不当植物。每份文件上限20MB。规格支持H/高度/株高、P/冠幅、胸径/地径等及明确米厘米转换；没有标注尺寸单位的常见带标签规格默认厘米。盆和株不能混合平均；通用品名可按库中A/B/数字分档的相应规格找价，明确不同品种仍分开。

旧“我的报价模板”独立模块已移除。打开新版时尝试将旧本地模板中的有效报价合并到库中，保留已有记录，不完整报价不猜测。旧原文件暂留旧IndexedDB作为恢复副本，界面不再提供模板管理。此前已被旧版本覆盖的历史报价无法凭空恢复，可重新导入原报价文件。
