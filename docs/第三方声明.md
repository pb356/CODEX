# 依赖、授权与安全边界

应用代码未引入 JavaScript、Python、.NET、联网库、遥测、自动更新器或外部应用框架。使用 Windows 自带 Win32、Shell、OLE、GDI+、Direct2D/WIC、DWM、WTS API。离线预览为本项目原生子程序，不引入视频或浏览器运行时。

交叉构建工具来自 Debian 官方 HTTPS 软件仓库，APT 校验官方签名的元数据及包哈希，没有关闭 TLS、签名或校验和验证：

- GCC MinGW-w64 x64 POSIX：Debian 14.2.0-19+27+b1，GCC GPLv3 + GCC Runtime Library Exception；静态链接的 libgcc/libstdc++适用运行库例外。
- mingw-w64：12.0.0-5，运行库许可包含 ZPL、MIT 等，winpthreads 静态链接。
- GNU binutils：2.44-3+12+b1，构建工具 GPLv3；不作为应用运行时安装。
- NSIS：3.12-1，安装器 stub 采用 zlib/libpng 类许可；压缩组件许可见上游 NSIS 发行版。
- 测试／格式工具可使用 clang-format 19 和 Wine 10；不打入安装包。

授权原文随源码 `licenses/` 提供，其中 `mingw-w64-copyright`、`gcc-mingw-w64-copyright` 与 `nsis-copyright` 来自上述 Debian 包。上游来源：https://gcc.gnu.org/、https://www.mingw-w64.org/、https://nsis.sourceforge.io/。

配置为本机当前用户私有数据，但不是加密文件；能够读取当前用户 AppData 的程序能够读取已保存路径。CRC 只检测常见损坏，不是密码学签名。拥有当前用户写权限的程序也能修改配置，软件对导入数据执行路径、存储大小、尺寸和长度限制（不设固定每筐项目配额）。

“打开”可能执行用户主动添加的脚本、程序或快捷方式；这与资源管理器打开同类项目的风险一致。添加引用本身不执行它们。不要打开来源不明的文件。主程序和安装器本次未进行 Authenticode 签名；不提供安全绕过步骤。

静态代码与 PE 导入检查覆盖引用变更、文件写入范围、ShellExecute 调用边界、网络 API 和外部运行库依赖。此前官方 Debian 漏洞数据源曾返回 403；本次已经成功补查，并记录 GCC／mingw 待核验记录，并将 NSIS 升级为修复版本 3.12-1，详见随安装附带的“安全检查.txt”或源码 docs/security/README.md。有限来源包匹配不等于完整二进制审计。未完成独立安全审计、Windows Defender 扫描或完整的 CVE/SBOM 自动匹配；不能据此宣称“无已知漏洞”或绝对安全。正式发布前需对最终哈希执行签名、安全扫描和供应链复核。


## 本轮开源研究与素材

研究 Desktop Frames+（MIT，保留 BirdyFences 来源说明）、Lively Wallpaper（GPL-3.0）、WPF UI（MIT）。固定提交、许可证链接、已读文件 SHA256 和采用边界见 `docs/references/open-source/`。没有复制、改编或链接三项目源码、资源、程序集或二进制，未捆绑 Lively 播放器，未引入 WPF UI／.NET。未来直接复用需按实际许可另行审查并保留归属或履行 GPL 分发条件。

正式预览素材由本次 image_gen 生成／编辑；来源、源稿尺寸与 SHA256 在 `assets/wallpaper/provenance.json`，离线随包提供。外部 Rawpixel 等预览只作设计方向研究，不属于已获授权的安装资源；不将署名当作授权。未打包三个开源项目的壁纸、图标或字体，不宣称素材独占版权或绝对无相似风险。

开发截图中的 Noto CJK 字体为云主机与 Wine 测试环境使用，不安装到用户系统。Linux 录屏工具依赖 X11 开发库，仅为开发工具，不打入 Windows 运行时。主程序启动的预览受 Job Object 管理；应用不注入或管理外部用户进程。
