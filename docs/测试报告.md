# 测试报告 · 桌面归纳盒 0.2.0

日期：2026-10-26。开发预览；不满足正式 Windows 发布验收条件。v0.1 报告单独保留在 `docs/archive/`，本报告只对应当前构建与本次证据。

## 实际环境

Debian 13 x86_64 云容器，GCC MinGW-w64 14.2.0、NSIS 3.12，Linux GCC 的 ASan/UBSan；Wine 10 + 隔离 Xvfb 1600×1000、96dpi。具体云 CPU 信息见 `verification/compatibility-environment.json`。这不是四核／8GB／SSD 的 Windows 10 验收环境，不用容器资源数据代替目标机器数据。

截图运行真实 Win32/GDI+ 控件，分层预览运行真实 Direct2D/WIC；Wine 内中文使用宿主 Noto CJK 字体替换，仅为兼容层截图设置，不修改终端用户的 Windows 字体配置。只读探针所见 OS build 19043 是 Wine 报告值，不是 Windows 实机证据。探针可以解析 Known Folder，但 IDesktopWallpaper 和 Explorer IFolderView2 未提供；没有更改桌面。

## 本轮发现并修正

- 初始化枚举与注册目录通知之间可能漏收：改为先注册通知再顶层核对。
- 后台结果队列满时可能静默丢失已接受任务：改为结果按键合并、满队列背压、消费后唤醒。
- 唤醒可能错误清除同时存在的锁屏暂停：采用独立暂停理由，恢复只清除相应理由。
- 只能检测单窗遮挡：改用原生区域逐步相减，识别多个不透明窗口共同覆盖；透明／分层窗口保守跳过。
- 兼容层把渐变绘成过亮圆斑：改用复用、明确预乘透明度的柔光纹理，中心 alpha 限制 ≤30/255，实际截图复核。
- 调整名称可能把旧版自定义图标／字号／透明度改成档位值：仅在相应控件实际改变时修改原值。
- 旧版备份被后续正常保存覆盖：增加独立的 v0.1 迁移备份，无法安全备份时停止写入。
- 分层叶柄曾超出画面进入预览底栏：裁剪到预览画布，底栏与绘图区分离。

真正 Windows 上用 `tools/measure-windows.ps1`；先由用户设定实际运行状态，再针对 PID 分别采样。例：`-AppProcessId 1234 -Phase hover-playing -Seconds 600`。新增阶段有 `wallpaper-off`、`wallpaper-energy`、`wallpaper-standard`、`wallpaper-with-hover`、`wallpaper-paused`、`large-list`；原有 `effects-off`、`hover-playing`、`fade-finished`、`soak` 保留。8 小时用 `-Phase soak -Seconds 28800`。

必须报告真实 CPU 型号、逻辑核、Windows build、8GB RAM／SSD、屏幕与缩放、项目数、效果档位及预览 PID。脚本 GPU 为所选 PID 单引擎最大值，不累计多引擎，不含 DWM；缺计数器报未测。采样峰值不等于瞬时峰值，也不能仅凭首尾值断言无泄漏。性能不达标先减星点与运动复杂度，保证文件安全和正常操作。

## 安全、许可与发布检查

三个指定项目已固定提交、核对许可证并阅读实际源码；[研究记录](references/open-source/README.md) 区分设计参考与直接复用。本次未复制／链接三项目代码或资源，运行时依赖未增加其框架。Lively 的 GPL-3.0 不被标成 MIT。

应用无网络库、监听端口、遥测或更新器。文件操作范围复核：原文件执行仅在明确打开路径；写入为本软件配置与测试私有文件。配置与拖放有路径／Unicode／长度／存储边界，CRC 只检错。唯一新增运行子进程是固定同安装目录的 `WallpaperPreview.exe`，用明确 lpApplicationName 启动，不经过命令解释器、不接受用户拼接命令；Job 只管理此子进程。只读探针不隐藏图标、不设壁纸、不发送私有 Shell 消息。安装／卸载逐项处理自身内容，不按引用删除原文件。

**未完成：**最终 Windows Defender／独立审计、签名验证、完整第三方 CVE／SBOM 匹配。此前 403 阻碍已解除，本次已成功读取 Debian 官方数据并完成有限的来源包匹配；发现 GCC／mingw 待核验记录，并将 NSIS 升级为修复该已知条目的 3.12-1 后重打安装包，见 [安全检查](security/README.md)。未完成最终二进制可达性审计，不能宣称“零漏洞”。当前构建仍是未签名预览，应在真正 Windows 环境按上述清单验收后再决定正式发布。
