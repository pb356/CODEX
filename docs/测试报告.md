# 测试报告：桌面归纳盒 0.1.0

日期：2026-10-26。状态：开发预览，不满足正式发布验收条件。

## 环境与证据

当前环境为 Debian 13 x86_64 Linux 云容器，不是 Windows 10 实机。编译工具版本、自动测试结果及产物哈希记录在 build/ 与 dist/；安装包可构建不等于已验证可安装。

已通过：Linux 原生 GCC + AddressSanitizer/UndefinedBehaviorSanitizer 的 14 组核心测试；覆盖路径限制、去重、事务式分类、状态持久化往返、配置逐字节损坏／截断拒绝、边界检查、10000 次确定性随机解码、5 筐 200 项模型。没有跳过测试组。

已通过交叉构建：GCC 14 MinGW-w64、NSIS 3.11；主程序为 AMD64 PE32+ GUI，安装器为 Windows 系统可运行的 NSIS 引导程序。PE 导入仅包含 Windows 系统 DLL，无外置 libstdc++、winpthread、Python、Node 或 .NET 依赖。ASLR、DEP/NX 和高地址熵链接选项已启用。主程序与安装器未签名。

Wine 10 + Xvfb 兼容运行测试提供额外证据：Windows 原子保存／备份、引用生命周期和原文件句柄释放检查通过。Win32 UI 的 7 组冒烟检查已通过，覆盖真实 HWND 尺寸、WM_DROPFILES、穿透样式恢复、动画结束停表、500 组快速折叠／展开、文件状态监视与外部重命名提示；最终运行结果见本次 build/ui-smoke-wine.log。兼容层的鼠标消息和窗体尺寸不能代替原生桌面输入及干净 Windows 安装测试。

复测发现并修正：缩放窗口的最小高度曾阻止折叠至标题栏；重复鼠标移动曾重置定时器；弹窗重入可能使容器引用失效；监视器注册失败时可能无效刷新。以上已增加对应限制与清理处理；仍需要 Windows 实机回归。

原文件不变的 Linux 测试仅覆盖不执行文件 I/O 的模型操作；实际 Windows 原子写入和原文件生命周期另有 tests/windows_tests.cpp，不能以 Linux 模型测试替代。

## 安全检查结果与阻碍

静态检查中，原文件写入只出现在临时文件测试；主程序写入目标限定为当前用户的软件配置，ShellExecuteEx 仅在双击或显式“打开”命令中调用。未使用命令解释器、全盘扫描、系统图标隐藏或全屏鼠标钩子；不对用户原文件调用移动或删除 API，配置自身的原子替换与临时文件清理由软件单独处理。安装器删除项逐一列出，不按引用删除原文件，不递归清理任意用户目录。配置有 CRC、大小与数量限制，CRC 不是安全签名。

Debian 官方漏洞数据源 `https://security-tracker.debian.org/tracker/data/json` 在当前环境被 HTTPS 代理拒绝（403 / CONNECT tunnel failed）。因此自动已知漏洞匹配未完成，不能报告零漏洞。云环境草稿已追加该域名；运行网络配置生效后需重新查询对应源包版本，再补上 Windows Defender 与最终签名／哈希核查。应用本身不依赖此网络访问。

## 性能：尚无实测结果

必须在四核 CPU、8GB RAM、SSD，5 筐／200 项的 Windows 10 x64 机器报告 CPU 型号、逻辑核数、OS build、分辨率、缩放与磁盘。当前 Linux 容器不符合基准，不能用编译或静止截图给出达标结论。

分别执行 tools/measure-windows.ps1（先手动设定实际运行状态，脚本不会模拟鼠标）：

1. `-Phase effects-off -Seconds 600`：关闭效果，初始化完成且无文件变化，观察 10 分钟。
2. `-Phase hover-playing -Seconds 600`：启用轻柔或标准效果，鼠标停留在筐内，确认星点动画实际播放。
3. `-Phase fade-finished -Seconds 600`：鼠标移出等待淡出结束，再测 10 分钟。
4. `-Phase soak -Seconds 28800`：至少 8 小时长时间运行，检查内存／线程／句柄趋势；同时记录 GDI 对象数。

示例：`powershell -File tools/measure-windows.ps1 -AppProcessId 1234 -Phase hover-playing -Seconds 600`。脚本保存 CSV、硬件信息、整机口径平均 CPU、专用内存均值与采样峰值、线程与句柄首尾值。GPU 统计为归属于所选进程的单个 engine 利用率最大值，不累计多引擎、不含 DWM；若计数器不可用必须报告未测，必要时用 WPR/GPUView 补测合成开销。
