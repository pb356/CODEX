# 热植壁纸参考图（待确认）

以下 8 张真实植物摄影仅用于确认植物形态、材质、层次与配色，不是正式壁纸，不代表已完成构图。Behance 与 Pinterest 当前检索返回 HTTP 403，先采用可核验作者和许可的 Wikimedia Commons 摄影，并保留原站检索入口。

默认构图方向：植物在左侧、左下和底部自然舒展；右侧 40% 为安静办公区，摆动范围也不进入核心留白。确认植物质感后再制作静态构图，再确认运动预览。
