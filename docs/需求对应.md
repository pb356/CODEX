# 需求对应与实现边界 · 0.2.0

用户的完整需求及两份附件一起实施；后续明确的海报／平面设计方向与静态稿确认优先于附件中的摄影描述。此表描述当前代码，不替代 Windows 实机验收。

| 范围 | 当前实现 | 尚缺条件／功能 |
| --- | --- | --- |
| 原生离线、普通用户 | C++/Win32、静态运行库、NSIS 当前用户安装、中文、无账户网络更新器 | 真正干净 Windows 10 离线安装未验证；未签名 |
| 引用与文件安全 | 只维护路径；明确打开才 ShellExecute；去重、跨框分类、引用移除、事务失败保护 | 办公／设计软件实际连续保存与所有外部文件系统情况未验证 |
| 创建与外观 | 空筐引导、托盘／标题入口、三主题、浓度百分比、系统颜色选择器、实时可取消预览 | 多屏实际 DPI 与读屏完整兼容未验证 |
| 大列表 | 可见项绘制、全量后台搜索排序、系统图标懒加载、96/框缓存、分段导入、滚动条、键盘首尾、边缘拖动滚动 | 10/200/1000/10000/11001 引用功能检查不等于性能达标；无固定每筐配额，仍有存储／内存边界 |
| 折叠、锁定、穿透 | 独立真实 HWND 高度、200ms 可关闭过渡、滚动／展开尺寸保存、全折叠／展开、托盘恢复输入 | 物理桌面点击／右键／拖动未在 Win10 验证 |
| 软光与星点 | 复用低透明度纹理、最多 6 星、约 180/300ms 出入、34ms 帧间隔、稳定／淡出停表、系统减少动画／高对比度 | GPU／CPU／内存增量与物理操作需实测 |
| 遮挡与会话 | 原生区域核对多个不透明窗口共同覆盖；锁屏、断开、休眠理由独立，恢复补扫 | 分层／透明／特殊外形窗口按保守策略处理，不声称能识别所有遮挡 |
| 桌面自动收件 | Known Folder 用户／公共桌面顶层，先监听再补扫，事件合并／溢出重扫；暂停／刷新；未分类及全部视图 | 通知溢出恢复路径与人工补扫共用，尚未在 Win10 注入实际内核溢出；OneDrive／Office／设计软件待实测 |
| 桌面整洁模式 | 必要系统入口、真实桌面入口与手动恢复说明 | 自动隐藏未实现／未开放；需恢复测试全部通过 |
| 热植美术 | 已确认原创静态方向；独立透明叶片与固定填补背景；离线打包、来源与像素记录 | 多布局、疏密、色调、原生 4K 素材未完成 |
| 热植动画 | 原生 Direct2D/WIC 预览、固定背景、独立叶柄、微幅异步运动、静态／15／30fps 上限与暂停、故障回退；Job 清理子进程 | 只是原生窗口预览。动态桌面挂载、系统壁纸备份／恢复未实现，不能代替完成应用验收 |
| 桌面层级 | 非置顶／NOACTIVATE 工具窗，无私有 Shell 挂载，无全屏输入遮罩 | Win+D 仍可能需托盘恢复，不能声称已解决；Lively 的 WorkerW 技术只完成源码研究 |
| 保存、安装与退出 | 版本校验／CRC／原子写／日常备份／独立 v1 迁移备份，退出清理，安装包列举自身内容，卸载不删原文件 | CRC 非安全签名；Windows 强杀／掉电、卸载、签名、防病毒与完整漏洞匹配待验 |

三个开源项目的固定版本、源码依据、采用与不采用项见 [研究记录](references/open-source/README.md)。可执行验收和性能采样方法见 [测试报告](测试报告.md)。
