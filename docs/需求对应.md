# 需求对应与实现边界

此表说明代码具备的路径与已知缺口，不替代 Windows 验收。所有 Windows 桌面操作与性能指标仍以测试报告为准。

| 需求部分 | 代码路径／实现 | 缺口或限制 |
|---|---|---|
| 一、原生离线应用 | C++ Win32，静态运行库，当前用户 NSIS 安装包，中文 UI，无网络组件 | 干净 Windows 实机安装与运行待验证；未签名 |
| 二、创建筐 | 首次引导与创建按钮、托盘／标题菜单入口、名称颜色透明度、工作区约束、拖动缩放锁定、删除引用确认 | 避让是有限次数错位尝试，不保证完全不重叠 |
| 三、外观设置 | 每筐独立设置、前景独立透明、滚动、吸附、合并自动保存、隐藏显示、默认关闭开机启动 | 设置为原生表单，颜色／数值输入；临时搜索和全局显示隐藏不是持久设置 |
| 四、引用安全 | 只改配置；SHGetFileInfo 使用 USEFILEATTRIBUTES 取通用图标；ShellExecuteEx 仅在明确打开时执行 | 操作系统关联程序和用户打开的快捷方式行为不由本软件控制 |
| 五、手动分类 | 去重、跨框事务转移、排序、手动排列、逐项批量、名称搜索、父目录变更通知与失效重定位 | 最多 24 个固定磁盘父目录；不追踪不确定的重命名；超限／网络／可移动路径手动刷新 |
| 六、穿透 | 每个独立分层窗，正常空白可接收 WM_DROPFILES，整框 WS_EX_TRANSPARENT；托盘设置／恢复 | 物理鼠标穿透与 Explorer 拖放仍待 Windows 测试；不模拟转发点击 |
| 七、桌面兼容 | 非置顶、NOACTIVATE、真实折叠窗口高度、无 Explorer 注入／私有接口／全屏输入层 | 普通工具窗不等价于桌面外壳控件；显示桌面后可能需要托盘恢复，多屏／DPI／会话行为未实机验证 |
| 八、低占用 | 事件式后台监视，最多一个工作线程、24 父目录，图标缓存有限，空闲无动画定时器 | 无 Windows 性能和 8h 数据，不能声称达到目标；极慢或异常文件系统可能挂住工作线程，退出有 1.5s 上限后随本进程终止 |
| 九、安全与配置 | 有界路径、数量／尺寸限制、版本+CRC、原子写+备份、损坏停止覆盖、用户目录存储；不联网不上传 | 配置不加密、CRC 不提供防篡改认证；未完成独立安全审计、CVE 完整匹配和防病毒扫描 |
| 十、交付 | 源码、双平台构建脚本、NSIS、中文说明、实测脚本、当前检查报告、可构建安装包 | 原生 Windows 构建／干净离线安装／卸载待实机验收，无签名证书 |
| 十一、折叠 | 独立状态、真实窗高、展开恢复、批量命令、200ms 过渡／关闭、无悬停自动展开 | 物理桌面输入、屏幕边缘及多屏实际行为待实机验收；布局存储为首选逻辑尺寸与物理位置 |
| 十二、光晕 | 绘制在现有 HWND 内，无独立命中层；34ms 更新间隔；最多 24 星点；250ms 离开淡出停表；静态模式；穿透／隐藏／锁屏停用 | 全遮挡仅识别单个非分层、不透明矩形覆盖；多个窗口组合遮挡不可靠，需保留限制；GDI+软件绘制开销待测 |
| 十三、验收 | 临时文件核心测试、Windows 持久化测试与同进程 Win32 UI 冒烟、Windows 性能采样脚本 | 兼容层测试不能代替 Win10x64桌面、GPU、8h、安全、安装卸载验收 |

未来继续开发应先完成真实 Windows 核心流程和文件安全验收，再评估是否需要调整公开桌面集成方案；不能加入真实文件搬动、修改原生图标或 Explorer 私有嵌入来掩盖限制。
