# 桌面归纳盒 0.1.0 预览版

目标：Windows 10 x64。本次交付为待 Windows 实机验收的预览构建，不作为生产版本。

## 安装与启动

双击 DesktopBoxes-0.1.0-x64-Setup.exe，安装到当前用户目录。无需管理员权限、账户、网络、Python、Node.js 或额外 .NET 运行时。安装包与主程序尚未签名；请遵守系统安全提示，不关闭或绕过安全防护。Windows 10 的系统与企业安全策略可能阻止未签名程序，发布签名需另行提供证书。

第一次启动只显示引导，不扫描桌面。填写名称、十六进制背景颜色和不透明度创建空筐；可以取消并稍后从托盘创建。可选名称：设计软件、进行中项目、植物素材、方案汇报、报价合同、临时文件。

## 文件引用

从桌面或资源管理器拖入文件、文件夹或原有快捷方式。软件只保存路径，不复制、移动、隐藏、重命名或删除原文件。桌面的原图标继续保留。文件夹仅保存为一个入口，不递归导入。

双击入口：交由系统默认程序打开原文件或快捷方式；快捷方式参数与工作目录由系统保留。只有明确执行打开才启动程序或脚本。编辑和保存由外部程序在原路径进行。

右键项目可打开、移除引用或重新定位。重新定位填写原文件的新完整路径，不会移动文件。失效条目显示“[失效]”，云文件显示“[离线]”。网络、可移动磁盘或无法判断的条目状态可能未知；需要用户主动打开验证。

同筐重复路径不重复添加，跨筐允许同一路径。批量添加分别报告成功与失败。拖动筐内图标到其他展开筐改变引用归属，目标已存在时保留源引用；拖动到本筐其他项目位置调整排列。不支持从筐向外拖出文件，不提供真实删除功能。

右键可按名称、扩展名排序；排序后的顺序继续保存，也可以手动调整。未带扩展名的项目归为同一类型，不通过读取文件内容判断类型。搜索仅查已添加的名称，留空恢复全部；搜索文字是当前会话筛选条件。

## 窗口与折叠

拖动标题栏移动；边缘调整尺寸。近邻边缘约 12 逻辑像素吸附；空间不足时可能重叠，请手动移动。锁定位置禁止移动、缩放，仍可打开入口。

标题栏“－／＋”折叠展开，双击标题文字也可切换。折叠动画约 200ms，完成后真实窗口高度仅为标题栏，不保留原内容输入区域。展开恢复首选尺寸、排列与滚动行位置，必要时仅移动本筐到显示器工作区内。全局缩放变化、屏幕变小或显示器移除时按当前工作区约束显示。

标题栏“⋯”打开菜单。托盘提供新建、逐筐设置、全部折叠／展开、隐藏／显示、光晕与动画总开关、开机启动和退出。开机启动默认关闭。整框穿透后，从托盘“恢复所有筐的鼠标交互”或逐筐设置恢复。

普通模式下空白区域接收文件拖入，不透传；整框穿透模式下整个窗体使用 Windows 分层窗体穿透样式，不模拟点击，同时停用光晕。软件没有全屏透明窗口或全局鼠标钩子。

## 光晕与设置

本筐菜单或托盘设置可修改名称、背景与文字颜色、不透明度、字号、图标、光晕颜色、亮度、范围与星点数。文字与图标不随背景透明度变化。为确保普通模式的空白区域能接收拖入，背景不透明度限制为 16–245（约 6%–96%）。轻柔与标准两档，无高负载预设。星点最多 24 个，普通刷新间隔 34ms，不采用视频或复杂模糊。

鼠标离开后约 250ms 淡出并停止定时器；折叠仅绘制标题栏。关闭动画或系统禁用客户区动画时使用静态光晕，关闭光晕则完全不绘制。隐藏、锁屏、挂起时暂停；可以确认被单个不透明矩形窗口完全覆盖时停止悬停动画，多窗口组合遮挡不能可靠判断。

## 保存、恢复与卸载

配置位于 `%LOCALAPPDATA%\DesktopBoxes`，正常修改后约 600ms 合并写入；正常退出再次保存。`state.db` 为当前配置，`state.bak` 为上一次成功保存前的配置，二进制格式带版本、长度限制和 CRC 检查。突然断电前尚未落盘的操作可能丢失。

主配置损坏时提示是否从备份恢复；恢复前保留 `state.corrupt`，已有该文件则停止覆盖，需先手动备份。无可用备份时禁止自动覆盖，请退出后备份整个配置目录再处理。不要手动编辑二进制配置。

托盘“退出”关闭所有窗口和监视任务。通过系统“应用和功能”或开始菜单卸载。卸载需先退出；默认保留配置，交互卸载时可以选择删除配置。卸载从不读取这些引用去删除原文件。静默卸载 `/S` 保留配置。

## 已知限制

普通非置顶工具窗口不是嵌入原生桌面的控件，未使用 WorkerW 私有接口、Explorer 注入或驱动。“显示桌面”可能隐藏本软件窗口；从托盘“显示全部”恢复。窗口的桌面层级、焦点、多屏及会话行为尚待 Windows 实机验收，不能保证与桌面外壳无缝集成。

只对最多 24 个固定磁盘父目录使用变更通知，不监控子目录、不扫描全盘、不自动追踪重命名。超出监视上限、不可访问目录、网络盘与可移动盘需菜单手动刷新。外部重命名后原引用失效时由用户重新定位，软件不会猜测文件身份。

支持最多 50 个筐，每筐 2000 个引用，总量 10000，配置 8MiB，图标缓存每筐 64 种扩展名。普通系统类型图标不读取设计文件内容，不解析快捷方式目标，不生成云文件预览。长路径由系统默认打开机制处理，可能受外部应用限制。

性能目标、8 小时稳定性、干净系统离线安装、Explorer 重启和原生桌面操作尚未完成 Windows 10 实机验证。完整清单见测试报告。
