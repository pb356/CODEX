# 桌面归纳盒 0.2.0 开发预览

目标为 Windows 10 x64。此构建包含原生主程序、离线分层运动预览及当前用户安装器；仍未通过真正 Windows 10 的完整验收，不作为正式生产版。

## 安装与首次使用

双击 `DesktopBoxes-0.2.0-x64-Setup.exe`，默认安装到当前用户目录，不请求管理员权限。无需登录、联网、Python、Node.js 或额外 .NET 运行时。主程序、预览、素材均随包提供；系统内置 Win32、GDI+、Direct2D/WIC 随 Windows 使用。

安装器和程序未进行 Authenticode 签名。请遵守 Windows 与企业安全提示，不关闭或绕过安全防护。云环境未验证干净系统安装；能构建安装器不等于已完成实机安装验收。

首次启动显示简短引导，选择“创建第一个收纳筐”。默认创建空筐，不扫描桌面。填写名称、选择主题及背景浓度即可；颜色选择、字号等在“更多外观选项”。可以取消，稍后从托盘或已有筐菜单创建。开机启动默认关闭。

## 引用、分类与滚动

从桌面或资源管理器拖入文件、文件夹、原有软件快捷方式。只保存原路径及排列，不在原目录创建快捷方式，不移动、复制、隐藏、重命名或删除原文件。文件夹作为单个入口，不递归导入。

双击或明确选择“打开原文件”才交给系统打开。文件保存仍由外部程序作用于原路径；快捷方式由 Shell 按原有目标、参数和工作目录处理。添加、搜索、排序不执行项目。

同筐同路径去重，跨筐允许同一路径。普通筐之间拖动只改变引用归属；重复目标保留源引用。移除、删除筐都只删除分类记录。批量导入分段处理，失败项可点提示查看，不取消其他成功项。仍在处理时退出会提示哪些引用尚待重新拖入。第一版不提供向桌面拖出并真实移动文件的行为。

右键菜单或 Ctrl+F 按已添加名称搜索，支持手动、名称、类型排序，覆盖完整列表。新增文件不会撑大筐或缩小图标；滚轮、触控板累计滚动、可拖动滚动条用于浏览。Tab 切换标题按钮及文件区；箭头、Home/End、PageUp/PageDown 浏览，Enter 打开，Esc 取消选择。Delete 仅移除普通筐中的引用。完整名称与路径通过悬停提示查看。

失效引用标记异常，可重新定位或移除。普通引用仅有限监听最多 24 个固定磁盘父目录，不猜测重命名、不搜索全盘；网络／可移动路径或超出监视范围可手动刷新。系统图标后台按需加载，每框缓存上限 96，不扫描设计文件内容、不自动获取云端预览。极慢 Shell／文件系统调用仍可能延迟后台任务，不能保证所有第三方图标处理器均及时返回。

## 可选桌面收件箱

从托盘启用“桌面收件箱”，或在软件设置→桌面收件主动启用。只有启用后才通过 Known Folder 接口枚举真实用户桌面和公共桌面顶层，兼容桌面路径重定向；不重定向保存位置，不读取文档内容。

首次启用纳入已有项目，新增／保存／替换的项目维护为同一路径引用；通知合并后更新，不表示文件已保存完成。可识别的临时下载、保存与锁文件只过滤展示；合法零字节文件与文件夹保留，不递归收件。

默认“未分类”：拖至普通筐会保留真实桌面入口，并从未分类视图排除。移除最后一个普通分类后自动回到未分类。“全部桌面文件”显示完整库存，“查看新收件”由用户主动跳转；平时新增不强制跳到顶部。

支持暂停、立即刷新、打开真实桌面；启动、恢复与通知溢出做有界顶层补扫。目录暂不可用时保留此前入口并提示未更新，不声称监听健康。原生桌面图标仍保留。桌面整洁模式尚未开放，恢复测试完成前不会自动隐藏图标；手动恢复方法为桌面右键→查看→显示桌面图标。托盘另有此电脑、回收站入口。

## 筐的外观与交互

拖动标题移动，边缘缩放，锁定仅禁止移动和缩放。折叠按钮、双击标题、托盘“全部折叠／全部展开”均可使用。折叠通过实际缩短 HWND 释放原内容区，保留名称与项目数；展开恢复尺寸、排列及滚动，不因鼠标经过自动展开。拖动与双击分开处理。折叠过渡约 200ms，可关闭。

每筐有雾白、松影、烟蓝主题，正文、图标与背景透明度分开。设置分外观、特效、布局；名称、主题、百分比浓度和图标档位为常用项。高级颜色使用系统选择器，无需输入 HEX。实时预览“完成”保存，取消／Esc／关闭恢复；不修改文件引用。旧版自定义图标及字号不会因修改名称被强制改成新档位。

正常模式空白可接收拖入。整框穿透后标题、图标、滚轮和拖放均停用，光感同时关闭；从托盘“恢复鼠标交互”恢复。筐外没有透明输入层；不模拟或转发点击。

光感默认柔和，另可选关闭或少量星点，最多绘制 6 个。光感颜色、强度、范围可调；纹理复用，中心透明度上限约 12%，默认更低。鼠标移入约 180ms 出现、移出约 300ms 淡出；柔光稳定后停表，星点模式有轻微持续动画，上限约 30 fps。折叠只画标题，隐藏／锁屏／挂起／确认完全遮挡时停止。减少动画时静态，高对比度时停止装饰光感、采用系统可读颜色。

## 分层叶片运动预览

软件设置→壁纸→“打开分层运动预览”。这是明确标注的原生审阅窗口，不是动态桌面挂载，不更改系统壁纸。沿用已确认海报风格与右侧办公留白，固定背景配合花烛、龟背竹、芭蕉独立图层，围绕固定叶柄点轻摆；没有整图平移、声音或鼠标视差。

默认节能上限 15 fps，标准上限 30 fps，静态没有帧定时器；减少动画自动静态。隐藏、确认遮挡、锁屏、休眠、远程及节能条件暂停，恢复排除暂停时间；绘制故障回退已确认静态图。由主程序打开时，主程序退出也会清理预览子进程。

当前只提供右侧约 40% 留白的分层稿。疏密、留白多布局、色调调整、原生 4K 素材及真正桌面挂载未完成，不提供可点击但无效的设置。源稿尺寸与来源记录在 `assets/wallpaper/provenance.json`；不要把预览称为已通过的动态桌面功能。

## 保存、恢复与卸载

配置在 `%LOCALAPPDATA%\DesktopBoxes`，约 600ms 合并写入，退出再次保存。`state.db` 为当前配置、`state.bak` 为上一次成功保存前状态。旧版 v0.1 在读取后、写入新格式前保存字节不变的 `state-v0.1.db`，与日常滚动备份分开；备份不能安全建立时停止写入并提示，不覆盖另一份不同的迁移备份。新格式配置不供旧版直接读取，回退旧版应先备份再恢复旧版配置。

损坏配置需按提示从备份恢复；恢复前保留 `state.corrupt`，无法安全备份则停止覆盖。配置带版本、CRC、路径及尺寸检查，不加密；CRC 不提供防篡改保证。配置大小安全上限 256MiB，最多 50 个筐，不设固定每筐项目配额，容量仍受系统资源影响。

托盘有明确“退出”。从系统“应用和功能”或开始菜单卸载，先退出程序。卸载只列明删除自身安装文件及当前用户启动项；可选保留或清除软件配置，不按引用操作原文件。静默 `/S` 卸载保留配置。

## 已知兼容边界

筐仍使用非置顶工具窗口，无 Explorer 注入、驱动、全屏鼠标钩子或私有 WorkerW 挂载。Win+D 后可能需托盘“显示全部”恢复。动态桌面和图标隐藏依赖真实 Windows 恢复、层级与输入验证，目前保持未开放。

Windows 10 实机离线安装、桌面点击穿透、多屏 DPI、Explorer 重启、办公与设计软件保存、CPU/GPU/内存目标及 8 小时稳定性仍待验证。具体通过／失败／未验证项见测试报告。
